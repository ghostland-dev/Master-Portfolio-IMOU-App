# Portfolio IMOU

Personal portfolio and client portal of Ismail Mouyahada.

## Features

- Portfolio, blog and appointment booking
- Client dashboard: projects, invoices, files, messages
- Analytics

## Tech Stack

- shadcn/ui (Radix UI)

## Getting Started

```bash
git clone https://github.com/ghostland-dev/portfolio-imou.git
cd portfolio-imou
npm install
```
